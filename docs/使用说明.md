# 替身计时器 · 使用说明

> 目标：雷电模拟器对局中，当顶部菱形格数值“恰好减 1”时，自动启动/重置 15.00 秒倒计时，
> 以半透明置顶框显示左右两侧独立倒计时。

## 1. 安装与启动

- 方式一（推荐）：运行 `tools/publish.ps1` 后，进入 `publish` 文件夹，双击 `NaruttoTimer.App.exe`（默认框架依赖，需本机已装 .NET 8；如已联网可改用 `-SelfContained` 生成免装版本）。
- 方式二（开发）：在仓库根目录执行 `dotnet run --project src\NaruttoTimer.App`。

首次启动后，程序会在可执行文件同目录下创建 `data/`（配置与事件日志）。

## 2. 首次连接

1. 启动雷电模拟器，进入任意对局（页面顶部需显示菱形格）。
2. 点击 `[刷新设备]`，状态灯变绿且显示 `雷电模拟器 emulator-7834`。
3. 点击 `[连接]`，建立 screenrecord 视频流（首次自动查找 scrcpy/adb 与 FFmpeg 组件）。
4. 点击 `[开始识别]`，进入识别循环，预览区实时显示画面。

> 若提示找不到设备：请在 `[设置]` 中确认 adb 路径，或先启动雷电模拟器。
> 找不到 FFmpeg：请在 `[设置]` 中把 `scrcpy/FFmpeg 目录` 指向 `scrcpy-win64-v4.1\scrcpy-win64-v4.1`。

## 3. 区域框选（重要）

菱形格位置需框选识别区域，否则两侧显示“待框选”、识别结果为空：

1. 确保已连接并预览（画面可见）。
2. 点击 `[区域配置]`。
3. 输入左（区域A）、右（区域B）的 `x, y, 宽, 高`（相对当前预览帧坐标）。
4. 点 `[测试识别]` 验证，看到“格数 4/6 · 值”后再点 `[保存]`。
5. 建议左、右区域分别框住对应侧的菱形格，宽高略大于菱形排布。

> 提示：坐标需与“区域配置”卡片一致；6 格场景会自动向屏幕中心延伸判定。

## 4. 取色校准

颜色阈值默认值可能需按实际画面微调：

1. 点 `[取色校准]`，在冻结画面上点击菱形像素。
2. 分别点 `[设为亮]`、`[设为暗]`（亮=天蓝/高亮，暗=深蓝黑；橙红突变归亮）。
3. 连续多点几次覆盖亮度波动，点 `[保存]` 生效并写入 `data/calibration.json`。

> 值=4 突变偏橙红，识别器会将其归入“亮”计数。

## 5. 置顶框设置

- 位置锁定：控制面板开关；锁定时不可拖动/缩放。
- 背景透明度：滑块 10%~90%（默认 55%），随拖随改。
- 数字颜色：左绿右红（默认），可在 `[设置]` 中改 `#RRGGBB`。
- 显示格式 `0.00  0.00`（无方括号、无标签），字号随框高、间距随框宽。
- 未锁定时可拖动移动、拖动右下角缩放手柄改尺寸。

## 6. 数据保存

- `[数据保存]` 打开事件列表；`[导出 CSV]` / `[导出 JSON]` 保存到指定位置。
- 事件按日期写入 `data/yyyy-MM-dd/events.jsonl`。
- 识别、触发、回合切换等日志写入 `data/yyyy-MM-dd/log.txt`。

## 7. 常见问题

- 预览关闭后识别照常运行：`实时预览` 开关只隐藏画面，不影响识别。
- 模拟器断开：状态变黄“重连中”，程序自动重连并重新推送视频流。
- 识别运行中退出：会弹窗确认。

## 8. 项目结构（发布）

```
publish/
├─ NaruttoTimer.App.exe     # 单文件主程序
└─ vendor\scrcpy\           # adb.exe、scrcpy.exe、scrcpy-server、FFmpeg DLL
```
