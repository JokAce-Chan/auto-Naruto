# 替身计时器 · 主界面设计（文本稿）

## 0. 总体
- 正常窗口应用（双击打开，非开机自启），支持最小化/最大化/关闭，开发期以 `dotnet run` 终端方式运行。
- 默认窗口约 1240×720，可缩放；整体分四层：标题栏 → 工具栏 → 主体区（左预览 + 右控制面板）→ 状态栏。
- 主界面只负责"配置 + 监控 + 控制"；实际识别走 scrcpy 无窗口视频流，关掉主界面预览不影响识别。

## 1. 标题栏
- 左侧：菱形 logo + 应用名"替身计时器" + 版本号（如 `NaruttoTimer v0.1`）。
- 右侧：最小化 `—` / 最大化 `□` / 关闭 `✕`（关闭时若识别运行中，弹一次确认：停止识别并退出）。

## 2. 工具栏（功能按钮区）
从左到右排列，分两组：

设备与识别组：
- 设备状态胶囊：指示灯（绿=已连接 / 灰=未连接 / 黄=自动重连中）+ 文字 `雷电模拟器 emulator-7834`（设备号可下拉选择）。
- `[刷新设备]`：重新执行 `adb devices`，更新设备列表与指示灯；无设备时提示先启动雷电。
- `[连接]`：建立 scrcpy 视频流（首次自动推 `scrcpy-server`、`adb forward` 端口）；已连接时变为 `[断开]`。
- `[开始识别]`：主开关（主题色高亮）。点击后启动 30fps 识别循环；再点变为 `[停止识别]`。未连接设备时置灰。

视图与配置组：
- `实时预览`（开关）：只控制主界面预览画面显示/隐藏；隐藏时显示"预览已关闭·识别照跑"遮罩，识别不中断。
- `[取色校准]`：打开"采样模式"——在预览图上点取像素，分别设定亮/暗 RGB 判定范围并保存（详见 §6）。
- `[区域配置]`：打开"区域框选"——在预览图上拖框定义左/右识别区域，可微调坐标、测试识别。
- `[数据保存]`：打开数据管理（识别日志、触发记录、配置导出/导入，详见 §7）。
- `[设置]`：打开设置对话框（默认阈值、帧率、scrcpy 路径、界面偏好等高级项）。

## 3. 主体区 — 左：实时预览
- 显示 scrcpy 裁剪出的顶部区域（约 2560×300，等比缩放），标注两侧识别区域：
  - 区域A（左）：绿色虚线框，标签"左"；区域B（右）：红色虚线框，标签"右"。
  - 框内每格菱形实时显示分类色（亮=天蓝、暗=深蓝黑、值总和4突变=橙红、无法分类=灰"?"），并在框下显示当前值。
- 置顶框预览：半透明白色悬浮小条（`0.00  0.00`），可在预览区内拖动模拟真实置顶框位置；仅供演示，实际置顶框独立于主窗口。
- 预览关闭遮罩：显示"预览已关闭·识别照跑"。

## 4. 主体区 — 右：控制面板（卡片式，固定宽 400px，可滚动）
### 4.1 识别状态
- 左/右各一行：侧标记 + 实时菱形小格（亮/暗）+ 格数徽标（4 或 6）+ 当前值 + 倒计时数字 + 状态徽标（倒计时中/已归零/加载中/丢失）。
- 第三行：回合切换检测状态（格数变化不触发；加载结束置 0.00）。

### 4.2 置顶框设置
- 位置锁定：开关（锁定时不可拖动，由主界面控制）。
- 背景透明度：滑块 10%~90%（默认约 55%，可自主调节）。
- 数字颜色：左绿右红，可选"自选"打开调色。
- 显示格式：`0.00  0.00`（无方括号、无标签，字号随框高、间距随框宽）。

### 4.3 亮 / 暗颜色阈值
- 显示当前"亮"（天蓝系）与"暗"（深蓝黑系）的 RGB 采样范围；提示"值=4 突变偏橙红"。
- 每项旁有 `[重新采样]` 快捷入口（等同打开取色校准）。

### 4.4 区域配置
- 区域A（左）/区域B（右）坐标与尺寸（x,y,w,h）。
- 格数模式：自动（4↔6）——识别时按侧自动判定格数，6 格时向屏幕中心延伸；锚点说明（左侧外侧、右侧外侧，或按识别结果自动调整）。
- 按钮：`[测试识别]`（立即识别一次并显示结果）、`[恢复默认]`。

### 4.5 触发规则说明（折叠卡片）
- 值恰好减 1 → 启动/重置 15.00s；增、减 ≥2 → 不动作，进行中的倒计时不打断。
- 格数变化 4↔6 → 不触发，新值继承旧值但不超新格数上限。
- 加载动画期间识别丢失 → 不触发不重置，颜色突变不计；重新稳定识别后该侧立即置 0.00（前后值相同可提前置 0.00）。
- 归零后保持显示 0.00。

## 5. 状态栏
- 左侧：`● 识别运行中 / 已停止`（绿/灰）+ `FPS 30` + `视频流 H.264 · 2560×300`（或 `裁剪区域`）。
- 右侧：单行滚动日志（时间戳 + 事件，如 `[12:00:01] 左值 4→3 触发，置顶框=15.00`）。

## 6. 取色校准（采样模式）
- 入口：工具栏 `[取色校准]` 或阈值卡片 `[重新采样]`。
- 流程：冻结当前预览帧 → 鼠标点击菱形像素 → 弹出该像素 RGB → 选择归类（亮/暗/其他）→ 自动扩展同色像素加入范围 → 实时显示判定预览（被归为亮的格高亮）→ `[保存]` 写入配置。
- 支持分别校准"亮"与"暗"，范围以"最小值~最大值"区间保存，重启后沿用。

## 7. 数据保存调用
- 自动记录：每次触发事件（时间、侧别、格数、旧值→新值、倒计时重置）、回合切换事件、加载事件。
- 管理界面：查看/过滤日志、导出 CSV/JSON、导入导出完整配置（区域坐标、阈值、置顶框参数）。
- 保存位置：程序目录下 `data/` 子文件夹，按日期分文件。

## 8. 模块与扩展接口（预留）
- 按"各自编译"划分五个模块：窗口采集识别、菱形区域配置与识别、置顶框数字、数据保存调用、取色校准。
- 模块间以接口解耦（采集层 → 识别层 → 规则层 → 显示层/数据层），便于后续追加功能，例如：在捕获窗口中叠加显示指定路径 PNG 图片、增加声音提示、多方案切换等。
