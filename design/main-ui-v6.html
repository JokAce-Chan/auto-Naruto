v6 改动

  1. 组头带图标：每个组头 = 三角 + 图标 + 组名；图标可在「图标设置」里换。
  2. 组头外轮廓：组头用与栏底「设置」完全同款的框（#20252D 底 + #343B47 边 + 圆角）；收起时就是一整条，展开时外壳包裹整组（组头 + 条目同一外框）。
  3. 「折叠图标候选」→「图标设置」：不再删除；目标分两排（组头 / 组内条目），点图标即套用，写入记忆。
  4. 折叠宽度修正：点「折叠为图标条」后固定 58px（此前被行内宽度覆盖，仍占 400）。
  5. 折叠仅手动：不做「拖到下限自动折叠」。

待你确认

  1. 组头图标与折叠条图标共用同一个（改一处两处都变）—— 已按此实现；若要分开告我。
  2. 「图标设置」组自己也占折叠条一格 —— 保留还是从折叠条里去掉？
  3. 展开后的组内底色（#181C23，比组头略深）合不合适？
  4. 记忆内容：栏宽 / 折叠态 / 各组开合 / 11 个图标位 —— 确认就是这些？
